# DROP CASCADE / ドロップカスケード

**玉・てこ・風船・シーソーを組み合わせる、縦長3Dルーブ・ゴールドバーグ・パズル。**
上から落ちてくる玉を、仕掛けを配置してゴールのカゴへ運びます。スマホでもPCでも、インストール不要の1ファイル完結型。

```
[スポナー] ＿↓
        ╲  ランプ    ◍ バンパー
   ▔▔▔▔▔▔╲___      ⚖ シーソー
              ╲       ◍ 風船 → ゴールが空中のステージも
   ▁▁▁▁▁▁▁▁▁▁▁▁▁╲___   (( ○ )) GOAL
```

## 特徴

| | |
|---|---|
| **3D描画** | Three.js（r160, ES Modules / CDN）。影・半透明・パーティクル付き |
| **リアルタイム物理** | 自作エンジン。固定タイムステップ 1/240s、球×回転OBB×1自由度プランク |
| **編集→実験の即反映** | ドラッグ設置 → ▶ でシミュレーション。失敗してもレイアウトはそのまま一瞬リトライ |

## 起動方法

`index.html` をブラウザで開くだけです。three.js を CDN から読むため **ネット接続が必要**です。

```bash
# そのまま開く
open index.html            # macOS
start index.html           # Windows

# 開発用に（更新時にキャッシュを避けたい場合）
npx serve .                # → http://localhost:3000
python3 -m http.server 8000
```

- **対応ブラウザ**: Chrome / Edge / Safari / Firefox の最新版（WebGL2 + ES Modules + importmap 対応版）
- **スマホ**: iPhone(Safari 16.4+) / Android Chrome。ホーム画面に追加するとフルスクリーンで遊べます
- GitHub Pages へ置くとそのまま公開できます（リポジトリ → Settings → Pages → `main`/root）

## あそびかた

> **目標**：上から落ちる玉を、指定数だけゴールのカゴへ入れる。

1. 下のトレーで **パーツをタップ**
2. 盤面を **ドラッグ** して設置（1個置く＝手数1）
3. 選択中のパーツは **回転スライダー** で角度調整、何度でも置き直し自由／🗑 で削除
4. **▶** でシミュレーション開始。**⏹** ですぐ編集へ復帰
5. 失敗しても配置は残ったまま **もういちど** で一瞬リトライ。少ない手数でクリアしよう

| 操作 | マウス | タッチ |
|---|---|---|
| パーツ設置・移動 | クリック＆ドラッグ | タップ＆ドラッグ |
| 回転（選択中） | 下スライダー | 下スライダー |
| カメラ移動 | 背景をドラッグ | 背景をドラッグ |
| ズーム | ホイール | ピンチ |
| 再生／停止 | `Space` | ▶ / ⏹ ボタン |

**失敗の自動判定**：全パーツが止まったまま約1.4秒、または36秒経過で「届かず…」。手数が足りないときはランプの角度を5°変えるだけで結果が大きく変わります。

## パーツ一覧

| パーツ | 名称 | 挙動 |
|---|---|---|
| ● | **玉** | 再生と同時にその位置から登場。別の仕掛けを叩く“打撃用”にも使える |
| ◣ | **ランプ** | 斜面。玉を転がして横へ運ぶ基本パーツ。角度が命 |
| ▣ | **ブロック** | 壁。玉を受け止め、軌道を区切る |
| ◉ | **バンパー** | 高反発の弾む球（反発係数 0.92）。玉を勢いよく跳ね返す |
| ⋀ | **じょうご** | V字導線。バラけた玉を一点に集める |
| ⚖ | **シーソー** | ピン留めプランク。玉の重みと衝突で傾き、端から滑り落とす。離れると復元 |
| ⌇ | **てこ** | 勢いよく玉が当たると倒れて通り道を開け、約1.5秒で自動復帰するゲート |
| ◍ | **風船** | 触れた玉を抱えて浮上（ロープ長 1.4）。1個につき1玉まで。空中ゴール対策 |

> 💡 **てこは「速い玉」でしか動かない**（閾値インパルス約1.75）。ゆっくり転がってきた玉では止まったままなので、高い位置から落とす／バンパーで加速させるのがコツ。
> 💡 **風船の抱えた玉はロープ上限で停止**します。ゴール中心よりやや下（约0.5単位）にアンカーを置くと丁度よく届きます。

## 多言語対応

- UI・説明文・ヒント・結果表示がすべて切り替わります（6言語）
- 初回は `navigator.language` で自動選択。以後は **🌐 ボタン**（ゲーム中）または **設定 → 言語** で手動切替、選択は保存されます

追加したい場合は `I18N` に辞書を足すだけです：

```js
const I18N={ ja:{...}, en:{...}, zh:{...}, ko:{...}, es:{...}, fr:{...} };
const LANGS=['ja','en','zh','ko','es','fr'];   // ここにも追加
// キー例: play / levels / help_body / p_ramp / d_ramp / clear / fail ...
```

## セーブデータ

ブラウザの `localStorage` に保存されます（サーバー送信なし）。

| キー | 内容 |
|---|---|
| `dropcascade_v1` → `done[i]` | 各ステージの `{moves, stars}`（i は0始まり） |
| `...layouts[i]` | 編集途中のレイアウト `[{type,x,y,a}, …]` |
| `...lang / sound / music` | 言語・効果音・BGMの設定 |

- **リセット**：設定 →「セーブデータを削除」
- **引き継ぎ**：同じブラウザなら自動。別端末へは移行できません（仕様）
- ステージ解放条件は「1つ前のステージをクリア」

## カスタマイズ

すべて `index.html` 内の JavaScript を編集するだけでOKです。

### ステージを増やす / 編集する

```js
L({
  sp:'-3.4,16.8,5',       // スポナー: x,y,個数[,間隔秒] ; 区切りで複数可
  need:4,                 // ゴールに必要な玉数
  par:4,                  // 目標手数（★3の基準）
  st:`-4.5,-0.5,9,1 ; -4.5,13.7,9,0.5 ; 1.2,9.2,6.6,0.6`,  // 障害物: x,y,幅,高さ[,角度deg]
  inv:{ball:2,ramp:3,seesaw:2,balloon:1},   // 使用可能パーツ数（省略時は FULL）
  hint:'seesaw',          // ヒント種別: ramp/wall/bumper/funnel/seesaw/lever/balloon/chain/finale
}),
```

- **座標系**：`x ∈ [-4.5, 4.5]`（盤の幅9）、`y` は上方向、盤の高さ 18。玉の半径 0.34
- `st` の障害物は中心座標＋サイズ。**左端に寄せて片側だけ塞ぐ**書き方が定番です
  （例 `-4.5,13.7,9,0.5` → x が -9〜0 を覆う半分の棚）
- ゴール位置は `GX`（x座標の配列）と `GY`（空中ゴール用 `{index:[x,y]}`）で管理

```js
const GX=[2.6,0,-3.0, ...];          // ステージ順のゴールx（省略は 0）
const GY={7:[-3.5,5.6], 9:[2.9,4.4]};// ここだけゴールを空中に（風船用）
```

### 手強さの調整

| 定数 | 意味 | 既定値 |
|---|---|---|
| `sim.g` | 重力 | `-14.5` |
| `sim.dt` | 物理ステップ | `1/240` |
| `BR` | 玉の半径 | `0.34` |
| `resolve()` の `e` / `mu` | 反発／摩擦 | `0.22 / 0.16` |
| `th:1.75` | てこの作動閾値インパルス | `1.75` |
| `rope:1.4` | 風船のロープ長 | `1.4` |
| `st.idle>1.4` | 自動失敗までの静止時間 | `1.4` 秒 |

重力を上げると弾道が鋭くなり、てこが作動しやすくなります。摩擦 `mu` を下げるとランプ上の玉がよく滑ります。

## 技術解説

```
index.html ─┬─ I18N / SAVE / AUDIO        … 多言語・localStorage・WebAudio
            ├─ LEVELS                     … ステージ定義（DSL）
            ├─ THREE SETUP + mesh builders… シーンとパーツ外観
            ├─ COLLIDERS / PHYSICS        … 当たり判定とシミュレーション
            └─ UI / INPUT / LOOP          … HUD、ポインタ操作、メインループ
```

- **衝突**：回転する長方形（OBB）と球。局所座標で最近点→法線→押し出し→インパルス反発。めり込み対策に位置補正、微小衝突は反発ゼロ扱いにしてジャッタを防ぐ
- **シーソー／てこ**：ピン留め1自由度回転体として解く
  `J = −(1+e)·v_rel / (1/m + (r×n)²/I)` → 玉の速度とプランクの角速度へ配分。
  シーソーは復元トルク型、てこは「閾値で開き、タイマーで閉じる」 bistable 型
- **風船**：浮力＋アンカー回りのロープ拘束（円周外へ出たら射影して速度を除去）。抱えた玉は位置固定（フリーズ）
- **疑似3D**：玉は薄い板状のスラブ内だけを動きますが、z方向の跳ね返りと奥の壁テクスチャで立体感を確保。カメラは盤面高さに応じて自動フィット＋パン／ズーム
- **音**：すべて発振合成（三角波アルペジオ＝ゴール、ノイズバースト＝衝突 等）。ファイル参照がないため完全オフライン動作（three.js のみCDN）

## つまずきポイント / トラブルシュート

| 症状 | 対処 |
|---|---|
| 「three.js を読み込めませんでした」 | CDN に到達できません。ネットワーク確認後、再読み込み。企業ネットワークなら jsDelivr を許可 |
| 更新が反映されない | ハードリロード（`Ctrl/Cmd + Shift + R`）または `npx serve` 経由で開く |
| 音が鳴らない | ブラウザ政策上、**最初のタップ/クリック後に**音が出ます。▶ や 🌐 を一度押してから 🔊 を ON に |
| 玉が極端な挙動（めり込む・吹っ飛ぶ） | レイヤー負荷で物理が遅延している可能性。タブを増やさない／ズームしすぎない。`sim.dt` をさらに細かくすると安定します |
| コンソールの `computeBoundingSphere … NaN` | 旧版のパース不具合（区切り文字不一致）。現行版では解消済みです |
| セーブが消えた | localStorage はサイト単位（`file://` と `http://` は別領域）。同じ経路で開いてください |
